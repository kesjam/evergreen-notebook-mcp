# Gemini Instructions

This project is a model-neutral MCP helper for NotebookLM workflows.

When using or editing it:

- Prefer MCP tools for source packs, Studio prompts, runbooks, and validation.
- Use the full artifact prompt pack and agentic generation guide for complete notebooks.
- Suggest creative use cases only when they remain grounded in selected sources.
- Keep NotebookLM interaction through visible UI steps.
- Keep examples generic and public-safe.
- Separate historical frequency from prediction.

Do not introduce authentication, cookie access, or hidden NotebookLM endpoints.
