# Studio Prompt Patterns

## Data Table

Ask for decision-grade columns: metric, period, value, evidence, confidence, caveat, practical meaning.

## Infographic

Give a title, audience, visual zones, required numbers, and a caveat strip. Use dashboard language for operational analysis and avoid poster-style fluff.

## Slide Deck

Specify a story arc: human question, data boundary, trend, bottleneck, comparison, decision playbook, caveats, next data to collect.

## Audio Overview

Give hosts a role and emotional opening. Ask them to explain the distinction between historical probability and prediction in plain language.

## Video Overview

Specify format, visual metaphors, scene order, narration tone, and the exact misconception the video should correct.

## Report

Use a structured thesis with sections for evidence, limitations, competing interpretations, action plan, and an evidence/caveat table.

## Quiz and Flashcards

Test reasoning. Include traps where the correct answer rejects overclaiming, false precision, or unsupported predictions.

## Mind Map

NotebookLM may not expose custom prompting for mind maps. If so, improve the source pack and generate the map from selected sources.
