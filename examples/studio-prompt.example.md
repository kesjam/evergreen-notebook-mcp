# Studio Prompt Example

Create a professional infographic titled "Demand Is Up, Access Is Constrained."

Audience: A practical operator trying to understand whether historical activity creates personal opportunity.
Tone: Clear, respectful, and evidence-based.
Thesis: System activity can increase while individual access remains constrained by schedule, queue, and resource availability.

Required numeric anchors:
- Use only numbers present in selected notebook sources.
- Mark missing numbers as "not in source."

Required caveats:
- Historical probability is not prediction.
- A busy system does not automatically create individual opportunity.
- Missing schedule history limits personal conclusions.

Visual zones:
1. Year trend cards.
2. High-activity window.
3. Opportunity funnel.
4. Constraint board.
5. Caveat strip.
